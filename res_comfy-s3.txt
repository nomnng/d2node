Pearl GPU miner

USAGE:
  pearl-gpu-miner --wallet <address> --pool <host:port> [options]
  pearl-gpu-miner --gateway [https://]<host:port> [options]

REQUIRED:
  --wallet <address>    your prl1... payout wallet address
  -p, --pool <host:port>
                        the pool to mine to. Required — there is no default pool. A bare host:port is
                        treated as a Pearl pool over skip-verify TLS (so it also works through a
                        TCP/TLS forwarder you trust). Pearl pools use stratum+tcp://host:port,
                        stratum+ssl://host:port, or stratum+ssl-insecure://host:port. Known
                        Herominers/Kryptex/Luckypool endpoints may be passed as bare host:port.
                        FAILOVER: pass a comma-separated list (no spaces) — the first is the primary,
                        the rest are backups, e.g.
                        de.pearl.herominers.com:1200,fr.pearl.herominers.com:1200. On a connection
                        failure the miner moves to the next pool and keeps mining; each reconnect tries
                        the primary first. Each entry keeps its own scheme/auto-detected transport. (In
                        a HiveOS flight sheet, put the whole comma list in the Pool URL field.)

OPTIONS:
  --worker <name>       worker / rig name (default: this machine's name)
  --password <string>   stratum password. On AlphaPool (*.alphapool.tech) this pins static share
                        difficulty via the password field, e.g. --password 'x;d=65536'. Other Pearl
                        pools ignore it. (No short flag: -p is --pool.)
  --diff <N>            convenience for --password 'x;d=N' — pin AlphaPool static difficulty to N
                        (pool minimum 20000). Recommended for fast cards so the share rate doesn't
                        outrun submission, e.g. a 5090 → --diff 131072.
  --gpus   <list>       GPU ids to use, comma-separated, e.g. 0,1 (default: all)
  --no-tui              use classic line-mode output even on an interactive terminal
  --tui                 force the full-screen TUI even if terminal auto-detect skips it (--no-tui wins)
  --bind <addr:port>    start the read-only HTTP status API on this address (DEFAULT OFF), e.g.
                        --bind 127.0.0.1:3333. GET /api/v1/status only; no wallet/pool credentials.
  --noCpu               build share proofs on the GPU. DEFAULT on H100/A100 and mixed rigs containing
                        a non-consumer datacenter card. CPU-proof is the DEFAULT when any B200 is present
                        (correctness), or when every card is consumer sm_86/sm_89/sm_120. Force GPU proof
                        on any rig via env NO_CPU=1. Lowest CPU load at submit time.
